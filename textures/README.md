# Tractor concepts (design exploration, not wired into the dashboard)

- `index.html`: the preview page. Open it with `open textures/index.html` (works offline over file://).
- `tractor-current*.svg`: today's box tractor (3/4, side and top views) for comparison.
- `tractor-{A,B,C}-{iso,side,top}.svg`: A is a modern cab tractor, B an autonomous orchard tractor, C a compact utility tractor. The top view points nose up and marks the hitch point.
- `tractor-palette-{A,B,C}.svg`: the 3/4 view in all 8 fleet colours, plus T1 broken and T3 working with a sprayer.
- Recolour any single SVG with the CSS custom property `--body` (`<svg style="--body:#BF5AF2">`). Tyres, glass and chassis keep their own colours.
- `_build/`: `node _build/build.mjs` regenerates every file. The SVGs are projected from a three.js-style part list, so its numbers port directly.
- Recommended direction: **A**. It keeps today's silhouette and shows the most fleet colour from the camera. B's LiDAR mast can be added as an optional autonomy kit.
- `house-{current,A,B,C}-{iso,side,top}.svg`: depot "house" concepts (A machine shed, B autonomous fleet hub, C container yard) from `_build/houses.mjs`, generated by the same `node _build/build.mjs`. `house-*-scene.svg` shows each next to tractor A at scene scale. Recommended: **A**. Concepts only, not built in 3D.
- Tractor A is built in the dashboard from the same part list: `dashboard/src/scene/tractorModelA.js` (no autonomy kit).
